Conecte a fonte de dados

O painel lê de um endpoint GET no n8n que devolve os leads e as respostas em JSON. Crie um webhook (método GET) que retorne este formato:

GET /webhook/premonicao-dados → { "leads": [ { "nome","email","telefone","telefone_ddi", "evento","pagina","data_envio","utm": { "utm_source": "...", "utm_campaign": "..." } } ], "respostas": [ { "nome","email","telefone","data_envio","grupo","utm": {...}, "respostas_simples": { "idade","curso","promessa","dor","urgencia", "desejo","renda","investimento","pagamento" } } ] }

Depois de criar, ajuste DATA_ENDPOINT no topo do <script> desta página (ou abra com ?src=URL).
