Conecte a fonte de dados

O painel lê de um endpoint GET no n8n. O formato que você já envia (array plano, uma linha por resposta) é aceito direto — estas chaves:

GET → [ { "row_number": 2, "Data": "29/07/26 01:53", "Nome": "...", "Email": "...", "Telefone": 5538..., "Idade","curso","promessa","dor","urgência", "desejo","renda","investimento","pagamento", "UTM SOURCE","UTM CAMPAIGN","UTM MEDIUM","UTM CONTENT","UTM TERM" } ]

Ajuste DATA_ENDPOINT no topo do <script> (ou abra com ?src=URL). O GET precisa liberar CORS (Access-Control-Allow-Origin).
